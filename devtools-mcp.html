Chrome DevTools MCP Server

让 AI 助手直接控制浏览器，开启智能化开发新体验

🤖什么是 Model Context Protocol (MCP)?

Model Context Protocol (MCP) 是一个开放标准，用于连接 AI 助手和外部数据源及工具。 它允许 AI 模型访问实时信息、执行操作，并与各种服务和系统进行交互。

MCP 的核心思想是让 AI 助手能够：

  • 访问外部数据源和 API
  • 执行复杂的操作和任务
  • 与开发工具和系统集成
  • 提供更智能、更实用的助手体验

🛠️Chrome DevTools MCP Server

Chrome DevTools MCP Server 是一个基于 Model Context Protocol 的服务器实现， 它通过 Chrome DevTools Protocol (CDP) 让 AI 助手能够直接控制和检查浏览器。

核心功能

🌐 页面导航

控制浏览器打开、关闭、导航页面

📸 截图和快照

捕获页面截图和可访问性快照

🔍 元素操作

点击、输入、悬停等交互操作

📊 性能分析

记录和分析页面性能指标

🐛 调试工具

访问控制台、网络请求等调试信息

🎨 样式调整

实时修改页面样式和布局

💡应用场景

1. 自动化测试

通过 AI 助手自动执行测试用例，验证页面功能和交互。 无需编写复杂的测试脚本，只需用自然语言描述测试需求。

2. 性能优化

AI 助手可以自动分析页面性能，识别性能瓶颈， 并提供优化建议和实施方案。

3. 页面调试

快速定位和修复页面问题，AI 助手可以检查控制台错误、 网络请求、DOM 结构等，帮助开发者快速解决问题。

4. 内容提取

自动从网页中提取结构化数据，进行数据分析和处理。

5. 交互式开发

在开发过程中，通过自然语言与 AI 助手交互， 实时调整页面样式、测试功能、验证效果。

⚙️技术架构

基于 Chrome DevTools Protocol

Chrome DevTools Protocol (CDP) 是 Chrome 浏览器提供的调试协议， 它允许外部工具通过 WebSocket 连接与浏览器进行通信。

MCP 服务器实现

DevTools MCP Server 实现了 MCP 标准，将 CDP 的功能封装成 MCP 工具， 使得 AI 助手可以通过标准化的接口控制浏览器。

🚀快速开始

安装和配置

要使用 Chrome DevTools MCP Server，你需要：

  1. 安装 Node.js 环境
  2. 安装 Chrome DevTools MCP Server
  3. 配置 MCP 客户端（如 Cursor、Claude Desktop）
  4. 启动服务器并连接浏览器
